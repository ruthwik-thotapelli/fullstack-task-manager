# Full Stack Task Management Application

A production-style Full Stack Task Management web application built using the MERN stack (MongoDB, Express.js, React.js, Node.js) with custom logging middleware integration.

---

## Features

- Create Tasks
- View All Tasks
- Update Tasks
- Delete Tasks
- Filter Tasks by Status
- RESTful APIs
- MongoDB Database Integration
- Custom Logging Middleware
- Centralized Error Handling
- Responsive Frontend UI
- Deployment Ready

---

## Tech Stack

### Frontend
- React.js
- Vite
- Axios
- React Router DOM

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Deployment
- Frontend: Vercel
- Backend: Render
- Database: MongoDB Atlas
